# Features

Personal Raycast extensions for macOS: Notes (local markdown notes and tasks in a native floating window), Focus (calendar-driven focus sessions with app and site blocking) and Knobs (system switches).

## Notes

- **Floating notes window**: show or hide an always-on-top markdown editor over the notes folder; edits save 0.4 s after typing stops and a note changed by another program reloads. Status: stable. Surface: macOS. Entry point: Toggle Notes Window command (or `notes-panel toggle`). Tests: extensions/notes/test/text-view, extensions/notes/test/attachments.
- **Hidden markdown markers**: headings, bold, italic, strikethrough, inline code, links, list markers, task boxes, quotes, toggles and callouts are styled in place while the file stays raw markdown; markers never show, the caret skips them and Backspace or Delete removes a marker whole. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/text-view, extensions/notes/test/list-editing.
- **Action palette**: press `⌘K` to filter and run window actions (New Note, Open Today's Note, Duplicate, Browse Notes, Previous and Next Note, Toggle Task, Find, Copy, Reveal in Finder, Delete, zoom, Minimize, Formatting, Open Settings). Status: stable. Surface: macOS. Entry point: `⌘K` in the floating window (or `notes-panel palette`). Tests: extensions/notes/test/text-view.
- **New note with a title-following filename**: `⌘N` creates a note whose first line becomes its title, and the file is renamed on save when that line changes (the id in the filename never changes). Status: stable. Surface: macOS. Entry point: `⌘N` in the floating window, New Note in Browse Notes (or `notes-panel new`). Tests: extensions/notes/test/lib.test.ts, extensions/notes/test/list-editing.
- **Today's note**: open or create the daily note `YYYY-MM-DD.md`. Status: stable. Surface: macOS. Entry point: Open Today's Note in the `⌘K` palette or Browse Notes (or `notes-panel today`). Tests: extensions/notes/test/lib.test.ts.
- **Note switching**: `⌘[` and `⌘]` move to the previous or next note in last-edit order. Status: stable. Surface: macOS. Entry point: floating window. Tests: none.
- **Duplicate, copy, reveal and trash a note**: `⌘D` duplicates, `⇧⌘C` copies the markdown, Reveal in Finder shows the file, `⌃X` moves the note to the Trash with no confirmation. Status: stable. Surface: macOS. Entry point: floating window keys and `⌘K` palette. Tests: guessing: extensions/notes/test/lib.test.ts (duplicate only) and extensions/notes/test/text-view (the `⌃X` key only).
- **Find in note**: `⌘F` opens find for the current note. Status: stable. Surface: macOS. Entry point: floating window. Tests: none.
- **Zoom**: `⌘+`, `⌘-` and `⌘0` zoom in, out and reset, remembered across launches, with a short percentage pill. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/text-view.
- **Appearance setting**: choose System, Light or Dark for the window and its menus and popovers; remembered. Status: stable. Surface: macOS. Entry point: gear popover or `⌘,` in the floating window (or `notes-panel appearance-system|light|dark`). Tests: extensions/notes/test/text-view.
- **Font setting**: choose Sans Serif, Serif or Mono for note text and headings while code stays monospaced; remembered. Status: stable. Surface: macOS. Entry point: gear popover in the floating window (or `notes-panel font-sans|serif|mono`). Tests: extensions/notes/test/text-view.
- **Footer status**: the footer shows the note's place in the list and its character count. Status: stable. Surface: macOS. Entry point: floating window footer. Tests: none.
- **Formatting keys and bar**: `⌘B`, `⌘I`, `⇧⌘S`, `⌘E` wrap bold, italic, strikethrough and inline code, `⌥⌘1` to `⌥⌘4` set headings, `⇧⌘7`/`⇧⌘8`/`⇧⌘9` make numbered, bullet and task items, pressing again removes; the footer's "T" button opens the same choices as a bar. Status: stable. Surface: macOS. Entry point: floating window (or `notes-panel format` for the bar). Tests: extensions/notes/test/text-view, extensions/notes/test/list-editing.
- **Slash block menu**: type `/` at a line start or after a space to pick Text, Heading 1 to 4, bulleted, numbered or to-do list, quote, toggle, callout or code block from a filterable menu under the caret. Status: stable. Surface: macOS. Entry point: `/` in the floating window. Tests: extensions/notes/test/text-view, extensions/notes/test/list-editing.
- **Emoji picker**: type `:` and two letters to search about 780 emoji by shortcode and insert one, or close an exact name with `:` to convert it at once. Status: stable. Surface: macOS. Entry point: `:` in the floating window. Tests: extensions/notes/test/text-view, extensions/notes/test/list-editing.
- **Note link picker**: type `[[` to pick another note by title and insert a link to it; clicking the link opens that note in the window. Status: stable. Surface: macOS. Entry point: `[[` in the floating window. Tests: extensions/notes/test/text-view, extensions/notes/test/list-editing.
- **Links**: `⌘L` links the selection, pasting a URL over a selection makes a link, hovering a web link shows a bubble with Open, Edit and Copy, and right-click offers Copy, Open, Edit and Remove Link. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/text-view (guessing: link editing only; hover and right-click are not exercised).
- **Lists and tasks**: bulleted and numbered lists continue on Return, renumber as you go and nest with Tab and Shift-Tab; `[]` then Space starts a task, and `⌘↩` or a click on the box toggles it. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/list-editing, extensions/notes/test/text-view.
- **Quotes**: `| ` or `⇧⌘B` quotes a line, shown with a bar down its left; Return continues it and Return on an empty quote line ends it. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/list-editing, extensions/notes/test/text-view.
- **Collapsible toggles**: `> ` makes a toggle whose chevron collapses or expands the lines indented under it, remembered per note while the window runs, without changing the file. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/list-editing, extensions/notes/test/text-view.
- **Callouts**: the slash menu's callout puts lines in an outlined box; Return continues it and Return on an empty line ends it. Status: stable. Surface: macOS. Entry point: `/callout` in the floating window. Tests: extensions/notes/test/list-editing, extensions/notes/test/text-view.
- **Marker stacking and peeling**: typing a heading, toggle or quote marker on an already marked line combines or replaces markers, and Backspace at the text start takes off one marker at a time, innermost first. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/list-editing, extensions/notes/test/text-view.
- **Code blocks**: three backticks then Return or Space open a block with its closing fence, `⌥⌘C` wraps or unwraps lines, blocks get syntax highlighting, and each block has a language picker and a copy button. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/text-view, extensions/notes/test/list-editing.
- **Dividers**: `---`, `***` or `___` alone on a line draws a thin rule, removed whole by one Backspace or Delete. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/list-editing, extensions/notes/test/text-view.
- **Typography replacements**: typed `->`, `=>`, `<-`, `--`, `>=`, `<=` and `...` become arrows, an en dash, comparison signs and an ellipsis, undone by one `⌘Z`, never inside code, link addresses or pastes. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/list-editing, extensions/notes/test/text-view.
- **Date keywords**: `@today`, `@tomorrow` or `@yesterday` followed by Space, Return, Tab or punctuation becomes the local date, undone by one `⌘Z`. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/list-editing, extensions/notes/test/text-view.
- **Date chips**: a date standing on its own in a note sits on a faint accent chip. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/list-editing, extensions/notes/test/text-view.
- **Undo and redo**: `⌘Z` and `⇧⌘Z` undo and redo, each typing rule and formatting key is one step, and the selection and reading position are kept. Status: stable. Surface: macOS. Entry point: floating window. Tests: extensions/notes/test/text-view.
- **Menu bar attachment**: attach the editor to a menu bar icon that opens it under the icon, keeping the open note and undo history. Status: stable. Surface: macOS. Entry point: gear popover, Attach, Menu Bar (or `notes-panel attachment-menuBar`). Tests: extensions/notes/test/attachments.
- **Notch attachment**: attach the editor to the notch as a compact card that opens on hover and stays open on click or the shortcut; `Esc` and `⌘W` collapse it. Status: stable. Surface: macOS. Entry point: gear popover, Attach, Notch (or `notes-panel attachment-notch`). Tests: extensions/notes/test/attachments.
- **Shared notch with Focus**: when Focus also uses the notch, the card shows Focus and Notes tabs switched by hovering, with Focus's countdown, Pause/Resume, Complete and a More menu (Edit, Cancel, moves, Extend); with an older Focus helper the editor falls back to a floating window. Status: stable. Surface: macOS. Entry point: notch attachment while a Focus session runs with Countdown set to Notch. Tests: extensions/notes/test/attachments, extensions/focus/test/helper.
- **Window commands**: drive the running window from a shell with `toggle`, `show`, `hide`, `new`, `today`, `open <path>`, `format`, `palette`, `appearance-*`, `font-*`, `attachment-*` and `quit`; later launches forward to the one running window. Status: stable. Surface: macOS. Entry point: `extensions/notes/assets/notes-panel <command>`. Tests: guessing: extensions/notes/test/attachments (the attachment commands only).
- **Browse Notes**: search note titles and contents, see pinned notes on top and open task counts, view a note's detail, edit it in a form, open it in the floating window (`⌘⇧F`) or another app, duplicate, copy, reveal or trash it. Status: stable. Surface: macOS. Entry point: Browse Notes command. Tests: extensions/notes/test/lib.test.ts (note naming, titles, duplicate and pins only; search, the detail and edit screens and the open, copy, reveal and trash actions are not exercised).
- **Pinned notes**: pin or unpin a note (`⌘⇧P`) so it stays on top in Browse Notes, with pins following renames; the files are not touched. Status: stable. Surface: macOS. Entry point: Browse Notes command. Tests: extensions/notes/test/lib.test.ts.
- **Quick Capture**: append text to today's note, add a task, or create or append to a note from a form. Status: stable. Surface: macOS. Entry point: Quick Capture action (`⌘K`) in Browse Notes. Tests: extensions/notes/test/lib.test.ts.
- **Tasks**: see every `- [ ]` line across all notes grouped by note, filter open, done or all, toggle done with Return, open the note, or add a task to today's note (`⌘N`). Status: stable. Surface: macOS. Entry point: Tasks command. Tests: extensions/notes/test/lib.test.ts.
- **Notes folder setting**: choose the folder the notes live in (default `~/.raycast/notes`). Status: stable. Surface: macOS. Entry point: Notes Folder Path preference in Raycast. Tests: none.
- **Link-safe renames**: when the window renames a note, links to it in every note are rewritten, a stale link still opens the note through the rename log or its id, deleted notes' ids are never reused, and older filenames get an id once. Status: stable. Surface: macOS. Entry point: floating window saves and listings; `.note-renames.jsonl` in the notes folder. Tests: extensions/notes/test/list-editing, extensions/notes/test/lib.test.ts.

## Focus

- **Focus Today**: list today's events from the startable calendars in Now and Later sections and start a session that runs until the event's planned end; starting another sends the open one to the end card first. Status: stable. Surface: macOS. Entry point: Focus Today command. Tests: extensions/focus/test/lib.test.ts, extensions/focus/test/helper.
- **Session controls in Focus Today**: the running session sits on top with its state, time left and blocking profile, and actions Pause or Resume, Extend by 5, 15, 25 or 45 minutes, Stop, Finish with rating and note, and Discard Session. Status: stable. Surface: macOS. Entry point: Focus Today command. Tests: extensions/focus/test/lib.test.ts, extensions/focus/test/helper.
- **Ad-hoc session**: start a session with a goal, a length (15, 25, 45, 60, 90 or 1 to 1440 minutes), a calendar to file it under (last one remembered, or No Calendar) and a blocking profile. Status: stable. Surface: macOS. Entry point: Ad-hoc Session command. Tests: extensions/focus/test/lib.test.ts, extensions/focus/test/helper.
- **Pause and timed pause**: pause for 1, 2, 5 or 10 minutes or until Resume; a calendar session's countdown keeps running to the event's end while an ad-hoc session's clock stops. Status: stable. Surface: macOS. Entry point: countdown panel, menu bar or notch Pause, or Focus Today. Tests: extensions/focus/test/helper, extensions/focus/test/ui.
- **Floating countdown panel**: a glass pill over every window shows the time left with a green fill and the goal; hover shows Pause, Complete, a "…" menu (Edit, Cancel, Move to Menu Bar or Notch, Reset Panel Position) and a drag handle, and the position is remembered. Status: stable. Surface: macOS. Entry point: Countdown set to Floating panel in Focus Settings. Tests: extensions/focus/test/ui.
- **Menu bar countdown**: the time left in the menu bar with Pause, Extend, Stop and Move to Floating Panel or Notch in its menu. Status: stable. Surface: macOS. Entry point: Countdown set to Menu bar in Focus Settings. Tests: extensions/focus/test/ui.
- **Notch countdown**: a black island at the notch (or top centre without one) shows the time and a progress ring and drops into a card with Pause, Complete and "…" after a short hover. Status: stable. Surface: macOS. Entry point: Countdown set to Notch in Focus Settings. Tests: extensions/focus/test/ui.
- **Countdown display switching**: switch between floating panel, menu bar and notch from Focus Settings or each display's Move to items; the change shows within a second. Status: stable. Surface: macOS. Entry point: Focus Settings command, countdown menus. Tests: extensions/focus/test/ui, extensions/focus/test/lib.test.ts.
- **Completion sound and glow**: when a session reaches its end by timer, Complete or Stop, a sound plays and the screen edges glow green. Status: stable. Surface: macOS. Entry point: automatic at session end. Tests: extensions/focus/test/ui.
- **End card with rating and note**: a compact card at top centre takes 1 to 5 stars, a note, Extend (+5/+15/+25/+45 min) or Finish; left alone it fades and finishes with no rating, and using it keeps it until answered. Status: stable. Surface: macOS. Entry point: automatic at session end; Finish form in Focus Today as fallback. Tests: extensions/focus/test/ui, extensions/focus/test/helper.
- **Breaks between blocks**: "Take a break…" on the end card rests the same task for 5, 10 or 15 minutes with blocking off, then a ready card offers the next block, more break, or Finish. Status: stable. Surface: macOS. Entry point: end card. Tests: extensions/focus/test/helper, extensions/focus/test/ui.
- **App blocking**: while a session runs, a blocked app is hidden and a block card with one Snooze button covers where its window was. Status: stable. Surface: macOS. Entry point: automatic during a session, per its profile. Tests: extensions/focus/test/helper, extensions/focus/test/ui.
- **Site blocking in Chrome and Dia**: a blocked site in the active tab is replaced by a local block page with Snooze, which returns to the site. Status: stable. Surface: macOS. Entry point: automatic during a session, browsers chosen in Focus Settings. Tests: extensions/focus/test/site, extensions/focus/test/helper.
- **Snooze**: let a blocked app or site through for the snooze length (1, 3, 5 or 10 minutes), after which blocking applies again. Status: stable. Surface: macOS. Entry point: Snooze button on a block page; length in Focus Settings. Tests: extensions/focus/test/helper, extensions/focus/test/site, extensions/focus/test/ui.
- **Blocking profiles**: create, edit and delete named profiles (blocklist or allowlist, six built-in categories, extra apps and hosts) and pick a default profile per calendar; system apps such as Raycast, Finder and System Settings are never blocked. Status: stable. Surface: macOS. Entry point: Manage Profiles (`⌘⇧P`) in Focus Settings. Tests: extensions/focus/test/lib.test.ts, extensions/focus/test/helper.
- **Focus Settings**: pick startable calendars, an optional single log calendar, watched browsers, snooze length, "Also start Raycast Focus" and the countdown display. Status: stable. Surface: macOS. Entry point: Focus Settings command. Tests: extensions/focus/test/lib.test.ts.
- **Calendar log event**: at Finish the actual session is written as a new calendar event (in the session's own calendar or the log calendar) with focused time, pauses, blocked attempts, rating and note; ad-hoc sessions with No Calendar are not written. Status: stable. Surface: macOS. Entry point: automatic at Finish. Tests: extensions/focus/test/helper.
- **Waiting to be logged**: sessions whose event could not be written yet are listed with the reason, Retry, and Move Waiting Sessions to another calendar. Status: stable. Surface: macOS. Entry point: Focus Today and Focus Stats commands. Tests: extensions/focus/test/helper, extensions/focus/test/lib.test.ts.
- **Focus Stats**: see focused time and session counts for today and the last 7 days with a daily bar chart, time per calendar this week, and the last 20 sessions with rating, blocked attempts and note. Status: stable. Surface: macOS. Entry point: Focus Stats command. Tests: extensions/focus/test/helper, extensions/focus/test/lib.test.ts.
- **Edit a past session**: change a finished session's rating and note, which also updates its calendar event's Rating and Note lines. Status: stable. Surface: macOS. Entry point: Edit Session (`⌘E`) in Focus Stats. Tests: extensions/focus/test/helper, extensions/focus/test/lib.test.ts.
- **Delete or discard a session**: delete a session with its pauses, blocked attempts and its own calendar event, or discard the open session with no log, no confirmation. Status: stable. Surface: macOS. Entry point: Delete Session (`⌃X`) in Focus Stats, Discard Session (`⌃X`) in Focus Today. Tests: extensions/focus/test/helper, extensions/focus/test/lib.test.ts.
- **Also start Raycast Focus**: optionally start and complete Raycast's own Focus alongside each session. Status: stable. Surface: macOS. Entry point: "Also start Raycast Focus" in Focus Settings. Tests: extensions/focus/test/helper.
- **Session recovery**: a session survives a quick helper restart (running, paused, on a break or at the end card), and one interrupted for long is closed as abandoned with no calendar event, except a break, which always comes back and shows the ready card if its time already passed. Status: stable. Surface: macOS. Entry point: automatic at helper launch. Tests: extensions/focus/test/helper.
- **Shared notch with Notes**: with Countdown set to Notch, the Notes window's notch card can host the Focus countdown and controls while Focus keeps the session and the end card; Focus's own island comes back when Notes stops. Status: stable. Surface: macOS. Entry point: Countdown set to Notch plus Notes attached to the notch. Tests: extensions/focus/test/helper, extensions/notes/test/attachments.

## Knobs

- **Set Grayscale**: toggle the grayscale colour filter, or set its intensity from 0 to 100 (0 turns it off), confirmed by a HUD. Status: stable. Surface: macOS. Entry point: Set Grayscale command (optional level argument). Tests: none.
- **Toggle Lid Sleep**: toggle whether the Mac stays awake with the lid closed (needs the `lid` script in `~/.local/bin` and its sudoers rule, not in this repo). Status: stable. Surface: macOS. Entry point: Toggle Lid Sleep command. Tests: none.
- **Lid Sleep Status**: show in a HUD whether the Mac stays awake with the lid closed. Status: stable. Surface: macOS. Entry point: Lid Sleep Status command. Tests: none.
- **Toggle Caffeinate**: start or stop caffeinate to prevent idle and display sleep (needs the `caff` script in `~/.local/bin`, not in this repo). Status: stable. Surface: macOS. Entry point: Toggle Caffeinate command. Tests: none.
- **Caffeinate Status**: show in a HUD whether caffeinate is running. Status: stable. Surface: macOS. Entry point: Caffeinate Status command. Tests: none.
